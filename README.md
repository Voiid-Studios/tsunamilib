## 📖 About

TsunamiLib (TL) is a library plugin that Voiid Studios uses in several of its projects. It doesn't add anything new on its own; instead, it provides tools for creating plugins in a more unified way.

For server administrators, it's just another plugin on the list that will ensure the plugins continue to function properly.

For developers who want to use TsunamiLib in their projects, there is currently no official documentation covering all the methods in this library, but the [JDocs for TsunamiLib are active.](https://voiid-studios.github.io/tsunamilib/) You can learn how to use the library by exploring the open-source plugins from Voiid Studios!

![Divider](https://voiid-studios.github.io/stuff/assets/proyect/TsunamiLib/divider.png)

## ✨ Features

- 🧩 **Required Library**: Provides the shared foundation used by Voiid Studios' plugins.
- 🖥️ **Cross-Platform Core**: Automatic Paper/Spigot platform detection, plus Folia-aware scheduling so your plugin runs correctly on either.
- 🎨 **Adventure-Powered Messages**: A YAML-driven, multi-language message system with per-plugin prefixes — each dependent plugin keeps its own identity and its own language files, no shared/hardcoded prefix.
- 🖼️ **TsunamiGui**: A full inventory GUI toolkit — paginated, scrolling, and storage GUIs, item builders (banners, books, fireworks, skulls, maps), and NBT/PDC helpers, so you're not rebuilding menu logic from scratch in every plugin.
- 📋 **Structured Logging**: A unified console logger with consistent formatting across every plugin that depends on TsunamiLib.
- 🔄 **Update Checking**: Built-in update checker/downloader so dependent plugins can notify admins of new versions without their own implementation.
- 📦 **Lightweight Foundation**: Runs quietly in the background — no gameplay content, no clutter, just shared systems your plugins can build on.
